## Instrucciones de Ejecución


### Demo

Ejecutar la demo que muestra competencia por asientos, confirmaciones y expiraciones:

```bash
mix run -e "CondorDelSur.Demo.ejecutar()"
```

Si PowerShell no dejar usar el `mix`, usar:

```bash
cmd /c mix run -e "CondorDelSur.Demo.ejecutar()"
```


### Tests

Para ejecutar las pruebas:

```bash
mix test
```

En Windows con:

```bash
cmd /c mix test
```
